# EventStoryLine v1.7 portable bundle

Extract at the NeoOLAF repository root and open `examples/RAGTreeDatasets/EventStoryLine_NeoOLAF_Native_Layer_Ablation_OneDoc_v1_7.ipynb`.

Scientific changes vs v1.6.3: relation-only focus; forward textual orientation, one global plot-role pass, target batches of six, relaxed narrative-link directness, and lightweight PRECONDITION-bias calibration. Event extraction and deterministic pair generation remain frozen. Cache handling retains the v1.6.3 short-path/best-effort fix. No `src/neoolaf` files are included or modified.

This version is designed to improve the v1.6.3 relation result, but no paid OpenRouter run was performed in the build environment, so improvement cannot be guaranteed until the notebook is executed.
